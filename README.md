# tobner.net

Source code of my personal website, [tobner.net](https://tobner.net). It is a minimal static site built with **Jekyll**, **HTML** and **CSS**, and deployed to **GitHub Pages** with GitHub Actions.

## Features

- Minimal, responsive single-page design (full-screen background image with a dark overlay)
- Shared layout and footer via Jekyll layouts and includes
- Custom `404` page
- Footer copyright year that updates automatically at build time
- Cache-busting query string on the stylesheet, so style changes show up right after a deploy
- Dockerized local development with live reload (also usable as a dev container)
- Automated deployment on every change to `src/` and once a month

`src/_site/` and `src/.jekyll-cache/` are generated by Jekyll and are ignored by Git.

## Local development

### Requirements

- [Docker](https://docs.docker.com/get-docker/) with the Compose plugin

### Start the dev server

```bash
docker compose up
```

Then open <http://localhost:4000>. The site is rebuilt and the browser reloads automatically whenever you change a file in `src/` (live reload runs on port `35729`).

Press `Ctrl+C` to stop the container. To also remove it, run:

```bash
docker compose down
```

### Dev container

The repository includes a dev container configuration (`.devcontainer/devcontainer.json`). Open the repository in VS Code (or any compatible editor) and choose **Reopen in Container**. It uses the `jekyll` service from `compose.yml` and forwards ports `4000` and `35729`.

## Deployment

The workflow in `.github/workflows/deploy.yml` builds `src/` with `actions/jekyll-build-pages` and publishes the result to GitHub Pages. It runs:

- on every push to `main` that changes files in `src/`
- on the **1st of every month** at 00:00 UTC (keeps the copyright year current)
- manually, via the **Run workflow** button (`workflow_dispatch`)

Changes outside `src/` (for example this README) do not trigger a deployment.

### Custom domain

The domain `tobner.net` is set in the `CNAME` file. Make sure the custom domain is also configured under **Settings → Pages** in the GitHub repository, and that the DNS records point to GitHub Pages.
