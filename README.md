# tobner.net

Source code of my personal website, [tobner.net](https://tobner.net). It is a minimal static site built with [Jekyll](https://jekyllrb.com/), HTML, and CSS, and deployed to [GitHub Pages](https://pages.github.com/) using GitHub Actions.

---

## Features

- **Minimal, responsive design**: Single-page layout featuring a full-screen background image with a dark overlay.
- **Shared templates**: Jekyll layouts (`_layouts/default.html`) and includes (`_includes/footer.html`) for reusable structure.
- **Custom 404 page**: Dedicated error page configured with Jekyll front matter.
- **Dynamic copyright year**: Automatically updates the footer copyright year at build time.
- **Asset cache-busting**: Query parameter on stylesheets tied to build timestamp (`?_={{ version }}`) ensures immediate updates upon deployment.
- **Containerized local development**: Docker Compose and VS Code Dev Containers support with live reloading.
- **Automated CI/CD**: Automatic builds on content changes and monthly scheduled rebuilds.

## Project Structure

```text
├── .github/workflows/   # GitHub Actions deployment workflow
├── src/                 # Jekyll source files
│   ├── _includes/       # Reusable components (e.g. footer)

└── CNAME                # Custom domain configuration for GitHub Pages
```

> **Note:** `src/_site/` and `src/.jekyll-cache/` are generated by Jekyll during builds and are excluded via `.gitignore`.

## Local Development

### Prerequisites

- [Docker](https://docs.docker.com/get-docker/) with the Compose plugin

### Using Docker Compose

1. Start the Jekyll development server:
   ```bash
   docker compose up
   ```

2. Open [http://localhost:4000](http://localhost:4000) in your browser.

The server runs with `--livereload` enabled on port `35729`, so changes in the `src/` directory are automatically reflected.

To stop the server:
```bash
docker compose down
```

### Using Dev Containers (VS Code)

1. Open this repository in [Visual Studio Code](https://code.visualstudio.com/).
2. When prompted (or via the Command Palette: `F1` > **Dev Containers: Reopen in Container**), reopen the workspace in the container.
3. The Jekyll service starts with ports `4000` and `35729` automatically forwarded.

## Deployment

Deployment is fully automated with **GitHub Actions** via `.github/workflows/deploy.yml`:

- **Push to `main`**: Automatically triggers a build and deploys changes affecting the `src/**` directory to GitHub Pages (changes outside `src/`, such as documentation, do not trigger a build).
- **Scheduled**: Runs on the **1st of every month** at 00:00 UTC (`0 0 1 * *`) to keep time-dependent content (like the copyright year) current.
- **Manual**: Can be triggered on-demand via the **Run workflow** button (`workflow_dispatch`) in GitHub Actions.

### Custom Domain

The custom domain `tobner.net` is set in the `CNAME` file. Make sure that:
- The custom domain is configured under **Settings → Pages** in the GitHub repository.
- DNS records point to GitHub Pages.
